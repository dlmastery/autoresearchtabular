# SETUP — autoresearchtabular

## Prerequisites

- Python 3.10 or higher
- ~3 GB free disk for `HIGGS.csv.gz` + ~2.5 GB for the materialised NPZ
- Optional: CUDA-capable GPU for the deep tabular backbones (FT-Transformer,
  SAINT, NODE, TabM, etc.). Tier 1 (LR / RF / LightGBM / XGBoost / CatBoost)
  runs CPU-only.
- Network access to `archive.ics.uci.edu` for the one-time download

## Install

```bash
git clone https://github.com/dlmastery/autoresearchtabular.git
cd autoresearchtabular
python -m pip install -e .
```

The base install pulls in:

- `numpy`, `pandas`, `scikit-learn`, `scipy`, `pyyaml`, `psutil`
- `lightgbm`, `xgboost`, `catboost`
- `torch` (CPU or CUDA depending on your install)

For the deep tabular backbones that need the optional `transformers`
codepath:

```bash
pip install -e ".[neural]"
```

For development (`pytest`, `ruff`):

```bash
pip install -e ".[dev]"
```

## One-time data download

```bash
python scripts/download_higgs.py
```

This downloads `HIGGS.csv.gz` (~2.81 GB) into `.data_cache/higgs/` and
on the first `core.runner` run will materialise it to a NPZ
(`.data_cache/higgs/higgs.npz`, ~2.5 GB) for fast subsequent loads.

The download is **idempotent** — if the file is already present at the
expected size, it is left in place.

## Running the data-split audit

Before any experiments, run the audit:

```bash
python -m core.evaluation.audit --config configs/higgs.yaml --triple-check
```

This runs all 7 auditors and produces:

- `autoresearch_results/data_split_audit.json`
- `autoresearch_results/data_split_audit.md`
- `autoresearch_results/data_split_fingerprint.txt`

If any auditor fails, *do not* run experiments. Fix the underlying
issue (typically: corrupt download, missing file, mismatched feature
count) and re-run the audit.

## Running one experiment

```bash
python -m core.runner --config configs/higgs.yaml \
                     --recipe lightgbm_default \
                     --seed 42
```

The runner:

1. Pins to P-cores 0-15
2. Verifies the audit fingerprint matches the recorded one
3. Loads the reasoning blob for the experiment number
4. Validates the blob (Citation Rigor + word floors)
5. Loads data, instantiates the backbone, fits, predicts
6. Computes metrics (AUROC, AUPRC, ECE, bg-rej-at-sig-eff)
7. Computes composite, checks champion status
8. Writes `recipe.yaml`, `metrics.json`, `predictions.csv`,
   `reasoning_blob.json` (post-run)
9. Appends a row to `all_runs.csv`
10. Refreshes dashboard data

Per-run artefacts live at
`autoresearch_results/exp_{N:03d}_{backbone}/`.

## Running the full campaign

```bash
python scripts/run_campaign.py --config configs/higgs.yaml
```

The campaign script iterates over all 14 backbones, runs the 25
canonical experiments per backbone (recipes encoded in
`sota_catalog.yaml`), and handles crash-restart. If the process is
killed, re-running picks up where it left off (the next experiment
number is computed from `all_runs.csv`).

To restrict to a single backbone:

```bash
python scripts/run_campaign.py --config configs/higgs.yaml --backbone lightgbm
```

## Running the dashboard

```bash
python -m http.server 8000 -d dashboard
# open http://localhost:8000/dashboard.html
```

The dashboard reads `dashboard/data.json`, which is generated by
`scripts/sync_dashboard_to_docs.py` (run automatically by the campaign
script after each experiment).

## Running the third-party audit replay

```bash
python scripts/third_party_audit.py --config configs/higgs.yaml
```

This re-derives all 9 audit sections from scratch using only the
committed artefacts in `autoresearch_results/`. It does not re-train
any model — it verifies that the recorded results are consistent with
the recorded recipes, reasoning, and split fingerprints.

## Troubleshooting

### "Audit failed: split fingerprint mismatch"

The data-split fingerprint in
`autoresearch_results/data_split_fingerprint.txt` does not match the
freshly-computed one. Either:

- the NPZ was regenerated from a different CSV (rare; UCI may have
  updated the file)
- the loader was modified

Inspect `data_split_audit.md` for the diff. **Do not delete the
fingerprint file** — its presence is the audit's only persistent
state. Investigate the root cause first.

### "Composite formula fingerprint mismatch"

`composite.fingerprint` does not match the formula in
`configs/higgs.yaml`. Either someone edited the formula (refusing the
run is the correct behaviour) or `composite.fingerprint` is stale.
Diff the two and decide.

### "Reasoning blob: section 'cite' missing section/table/figure"

The cite block doesn't include `§N` or `Tab.N` or `Fig.N`. Add the
specific reference; bare URLs are not accepted.

### Out-of-memory on a deep tabular backbone

The default 16 GB VRAM cap is tight for full-batch FT-Transformer or
SAINT on 10 M rows. Fix in `configs/higgs.yaml`:

- reduce `subset_train_n` for HP sweeps (e.g., 1M)
- final winner experiment can use full 10 M with a smaller `batch_size`

### "P-core affinity failed"

Non-Intel CPUs or older Intel without P/E cores. Comment out the
`_pin_to_safe_cores()` call in `core/runner.py` or set
`hardware.pin_affinity: false` in the config.
